One original roast for make.fun's "One-Line Roast: The Gadget You Use Every Day" (137 characters, one line): the phone's battery has a union contract — 100% at nine, 3% by lunch, dead before dinner — yet it still has the nerve to ask for a rating. The sting is recognition: the battery dies on a schedule, but the rating prompt always finds its energy. `main.py` validates the line (1–200 characters, one line) and writes it to `/output/entry.txt`, then prints it to stdout.

## Run it

```sh
python3 main.py
```
